## ⚙️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Numesh20/numesh-portfolio.git
cd numesh-portfolio
```

### 2. Add your images
```
images/Profile.PNG      ← Square photo, 400×400px or larger
images/project1.jpg     ← E-commerce project screenshot
images/project2.jpg     ← Task management screenshot
images/project3.jpg     ← Business portfolio screenshot
```

### 3. Open in browser
```bash
# No build step needed — just open directly
start index.html        # Windows
open index.html         # macOS
```

### 4. Deploy
Upload to any static host — [GitHub Pages](https://pages.github.com/), [Netlify](https://netlify.com), or [Vercel](https://vercel.com).

## 🎨 Customization

### Color Palette
| Variable | Hex | Usage |
|---|---|---|
| Teal Accent | `#64ffda` | Buttons, borders, highlights |
| Dark Background | `#0f0f23` | Page background |
| Card Background | `#112240` | Section & card backgrounds |
| Text Primary | `#ccd6f6` | Headings |
| Text Secondary | `#8892b0` | Body text |

### Changing Colors
Find and replace these values in [`css/styles.css`](css/styles.css):
```css
#64ffda   /* Teal accent  */
#0f0f23   /* Dark bg      */
#112240   /* Card bg      */
```

### Adding a Project
1. Add screenshot to `images/`
2. Copy a `.project-card` block in `index.html`
3. Update title, description, tech tags, and links
